# Security policy

## Reporting a vulnerability

Please report security issues privately, not in public issues or pull requests.

- Preferred: GitHub private vulnerability reporting, from the **Security** tab of
  this repository ("Report a vulnerability").
- Or email **security@obilabs.dev**.

Include what you found, how to reproduce it, and the version or commit you tested.
We will acknowledge the report, keep you updated while we look into it, and credit
you in the fix if you would like. This is a small project, so please allow a
reasonable amount of time for a response.

## Scope

The Apps Script add-on in `apps-script/`: the checks, the "Check links" lookups,
the report email, and the requested OAuth scopes. Issues in Gmail, Apps Script or
the third-party lookup services themselves should go to those vendors.
